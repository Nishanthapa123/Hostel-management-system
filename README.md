# Hostel Management System

Vercel-ready React/Next.js hostel management demo.

## Run

```bash
cd vercel-app
npm install
npm run dev
```

Open `http://localhost:3000`.

## Demo access

- Admin: `admin` / `admin123`
- Resident: `STU-1002` / `9876543211`

## Deploy to Vercel

Import this repository and set the Vercel **Root Directory** to `vercel-app`.

The app currently uses demo data in React state. Connect a hosted database and authentication service before production use with multiple customers.
